Securing Small Wireless Networks

Explore how to identify and configure wireless router settings to strengthen network security and prevent common vulnerabilities. Review this briefing before moving to the Lab Activity.

SSID & Admin Security

  • SSID (Service Set Identifier): The public name of the Wi-Fi network. Must be changed from the default to avoid broadcasting hardware types.
  • Default Admin Passwords: Out-of-the-box router credentials (e.g., admin/password) are publicly known and must be changed immediately.
  • Pre-Shared Key (PSK): The password users type to join the network. Needs to be complex and separate from the admin password.

Wireless Encryption (WPA)

  • Unencrypted (Open): No password required. Data is transmitted in plaintext, visible to anyone nearby capturing packets.
  • WPA2: The long-standing standard using AES encryption. Very secure for most home and small office setups.
  • WPA3: The latest standard. Features "Forward Secrecy" to protect past data even if a password is compromised later.

WPS & Guest Networks

  • Wi-Fi Protected Setup (WPS): A convenience feature (PIN or push-button) that allows easy connection. Highly vulnerable to brute-force attacks and should be disabled.
  • Guest Networks: A secondary SSID that provides internet access to visitors but isolates them from your private devices, files, and printers.

Firmware & Firewalls

  • Firmware Updates: The core operating system of the router. Updating it patches known security vulnerabilities and bugs.
  • Firewall: Software or hardware that acts as a digital bouncer, monitoring incoming and outgoing traffic to block malicious data packets.
