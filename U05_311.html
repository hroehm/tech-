OS File Systems

Explore how an operating system organizes, describes, protects, and compresses the digital files we interact with every single day.

Filesystems & Allocation

  • Role: Organizes raw binary data on a disk into accessible files and folders.
  • Structure: Hierarchical (tree-like with subfolders) vs. Flat (single-level directory).
  • Allocation: Methods include Contiguous, Linked, and Indexed block tracking.

File Compression

  • Lossless: Preserves 100% of original data (ZIP, PNG, GZIP). Removes redundant patterns.
  • Lossy: Permanently removes some data to drastically reduce size (JPEG, MP3, MP4).
  • Efficiency: Compressing an already compressed file yields little to no reduction.

Encryption & Security

  • Encryption: Converts data into unreadable code requiring a decryption key.
  • Symmetric vs Asymmetric: Single shared key vs. Public/Private key pairs.
  • ACLs & Permissions: Access Control Lists define Read, Write, and Execute rights.

Types, Metadata & Journaling

  • Common Filesystems: NTFS (Windows), ext4 (Linux), APFS (macOS), FAT32 (Removable).
  • Journaling: Logs changes before committing to disk to prevent crash corruption.
  • Metadata & Extensions: Hidden file properties (size, dates) and program associations.
